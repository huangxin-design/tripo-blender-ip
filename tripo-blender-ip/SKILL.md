# Tripo + Blender IP 精修

把角色身份、姿态和轮廓交给参考图约束，把可控的成片质量交给 Blender。默认目标是一张高质量静帧；已存在目标工程时从当前阶段继续。用户的新要求优先于这里的默认值。

## 开始与范围

- 读取本次参考图、现有模型/工程和已确认要求，区分附件内容与用户指令。简述目标、分工和验收方式，然后推进。
- 对同类静帧，可采用柔和棚拍、克制调色、清楚的材质层次。不得给不同 IP 强加红发、天使、羽毛、灰背景或相同姿势；尊重本次设计语言。
- 未指定分辨率时，沿用参考构图，先低分辨率预览，终稿以长边 4096 像素为候选默认，并写出实际宽高。用户指定 UHD、横版或平台尺寸时按其要求。
- 用户只问“能做到什么程度”时给可行性和分工，不提交生成任务。用户要动画、转台、游戏资产或打印时重新定义拓扑、背面、绑定或实体要求，不能把单视角静帧方案当作已满足。
- 自动触发表示自动选择此工作流，不授予无限次付费生成权限。沿用当前任务已明确的操作及预算授权；不重复询问同一已批准方案。新付费方案需要按 Tripo 技能要求展示并获得授权。分析、预览、已有模型的本地修整继续推进。

## 1. 拆分角色与工作

先用一个简短表格列出“部位 / 身份特征 / Tripo 基础 / Blender 补足 / 验收”。按画面影响排序：轮廓与姿势 → 脸与表情 → 标志配件 → 材质 → 微细节。

| 部分 | Tripo 适合负责 | Blender 需要检查和补足 |
| --- | --- | --- |
| 身体、头部、服装大形 | 比例、整体姿态、体块、基础 UV 与颜色 | 轮廓、接缝穿插、手脚、眼睑与表情；必要时局部雕刻/重建 |
| 头发、毛绒、羽毛 | 发型/衣服体积、主羽排列 | 轮廓发丝、分束和纤维；长羽厚度、层叠、方向与交叠 |
| 金属、机械件、鞋、道具 | 布局与复杂大形 | 简单规则件直接重建；薄片厚度、倒角、法线、连接关系 |
| 眼睛、皮肤、布料、漆面 | 基础颜色和 PBR 贴图 | 分材质/遮罩调整粗糙度、金属度、次表面与局部颜色 |
| 最终画面 | 生成预览供初筛 | 对照相机、光影、接地、色彩、真实分辨率输出 |

“拆分”先指职责与部位拆解，不等于每个部位都单独付费生成：

1. 固定视角静帧优先一次整体底模，保留人物与服装的相对位置。
2. Blender 中把需独立调材质/替换的部件放入独立对象或材质组；规则光环、纽扣、镜片等优先本地制作。
3. 大配件独立生成、Tripo 分件或多视图，只在当前交付确实需要、整体底模无法可靠修复且获得相应授权时采用。考虑装配比例、锚点、遮挡和额外调用费用，不默认一键拆全身。

## 2. 生成或复用底模

需要 Tripo 操作时，读取当前已安装的 `tripo-3d:tripo-3d` 技能，以及 [Tripo 执行与恢复](references/tripo-execution.md)。依赖未列出时在已安装技能目录搜索；仍不可用时先完成可做的本地工作并明确缺失能力，不凭旧参数盲发请求。

优先复用本任务已有 GLB、贴图和明确的任务 ID。新生成先展开真实 dry-run，确认模型、步骤、导出和预算；输出记录实际路径与每步任务 ID。**提交后本地报错不代表服务端未生成，恢复既有任务后再决定是否重试。**

## 3. Blender 构图与精修

读取 [Blender 精修与验收](references/blender-finishing.md)。保留原始模型/工程，另存工作版本。先检查贴图与朝向，用少量低成本视角找到主机位，锁定参考构图再动局部细节。

只修本次画面关键问题；对于可见的身份特征错误，不用调色掩盖结构错误。新增部件和材质修正保持可编辑。先预览，再决定细分、纤维数量和最终采样。每轮修改后检查脸、手、边缘与不同材质的交界。

用户提到“上次满意的天使”“沿用成片质感”，或需要验证参数来源时，读取 [已认可案例](references/approved-case.md)。它提供可验证的起点，不是通用坐标模板。

## 4. 4K 渲染与交付

- 从三维场景按目标尺寸重新渲染；不能把放大图当作完成了 4K 三维渲染。按噪点与硬件选择采样和降噪，最终一般保存 16-bit PNG。
- 验证实际图片宽高、位深、完整解码、非空内容；查看整图和脸、手、毛发、金属的原尺寸局部，检查降噪损失、穿插、杂毛和高光。
- 重新打开交付 `.blend`，确认相机、材质、资源与渲染设置可用；确认外部贴图已打包或一起交付。记录实际渲染设备与采样上限。
- 给出可点击的成片、`.blend`、原始模型及独立贴图路径。说明 Base Color、OpenGL Normal、ORM 通道；明确哪些是原始贴图，哪些改动只在 Blender 节点/灯光中，是否另行烘焙。
- 汇报实际完成的精修、仍可见的偏差、Tripo 每任务实付及总计。不要把虹膜改色说成重做表情，把纤维增强说成全羽毛重建，或承诺未经测量的还原百分比。

## 5. 可选的视频镜头建议

需要建议角色展示视频、短片镜头或静帧后的可选展示方式时，读取 [15 秒视频镜头参考](references/video-shot-suggestions.md)。其中包含已认可的镜头节奏、单向运镜、鞋子与羽毛分别特写、白模展示和 4K 规格建议；按当前 IP 调整，不默认套用整套镜头。

**此部分默认只给建议，不自动制作视频。** 不因技能触发、静帧完成或读取参考而建动画工程、试渲染、启动长任务或合成视频。只有用户明确要求执行，或当前会话已有同范围执行授权时，才落实；已有授权不重复询问。

## 完成前的质量门槛

身份特征与主构图对照通过；预览没有明显结构错误；目标尺寸和资源打包已核验；成片经过视觉检查；费用来自实际任务记录。若某项无法完成，标明具体缺项与影响，不把未验证的文件称为最终交付。
